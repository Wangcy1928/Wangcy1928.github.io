## 比赛过程

### I题
**题意**：
<p>设 T<sub>1</sub> = "Rounddog"。对于每个整数 i &gt; 1，定义 T<sub>i</sub> = T<sub>i-1</sub> + "g"，其中 + 表示字符串拼接。换句话说，T<sub>i</sub> 是字符串 "Rounddo" 后面紧跟着恰好 i 个字符 'g'。</p>
<p>给定一个字符串 S 和一个整数 k。考虑 S 的所有循环移位（字符串 S 的一个循环移位是通过选择一个位置，并将该位置之前的前缀移动到字符串末尾得到的）。你的任务是统计有多少个 S 的循环移位包含 T<sub>k</sub> 作为一个连续子串。</p>

---

**输入**：
第一行包含一个整数 t`（1 <= t <= 10^5）`，表示测试用例的数量。
对于每个测试用例，第一行包含一个字符串 S`（1 <= |S| <= 10^5）`。第二行包含一个整数 k`（1 <= k <= 100）`。
保证所有测试用例中 |S| 的总和不超过 `10^5`，并且 S 只包含大写字母和小写字母。
**输出**：
对于每个测试用例，输出一个整数，表示包含 T<sub>k</sub> 作为连续子串的循环移位数量。

---

**思路**：
由于循环移位可以通过将字符串复制一份拼接在后面来处理，令 `t = s + s`，则 s 的所有循环移位都对应 t 中长度为 sz 的连续子串。
目标子串 target = "Rounddo" + k 个 'g'，长度为 `7 + k`。
在 t 中查找所有 target 的出现位置 pos，对于每个 pos，它对应的循环移位起始位置 i 必须满足：
- i ≤ pos（target 起点在移位字符串内）
- i + sz - 1 ≥ pos + 7 + k - 1（target 终点在移位字符串内）→ i ≥ pos + 7 + k - sz
因此 i 的范围是 `[max(0, pos + 7 + k - sz), min(sz - 1, pos)]`。
用差分数组 diff 标记所有这些区间，最后做前缀和统计有多少个位置被覆盖，即为答案。

**代码**：
```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <cmath>
#include <queue>
#include <stack>
#include <set>
#include <map>
#include <unordered_set>
#include <unordered_map>
#include <numeric>
#include <iomanip>
#include <utility>
#include <tuple>
using namespace std;

const int MOD = 1e9 + 7;
const int INF = 0x3f3f3f3f;
const long long LINF = 4e18;
using ll = long long;

void solve() {
    string s;
    int k;
    cin >> s >> k;
    string t = s + s;
    int sz = s.size();
    string target = "Rounddo" + string(k,'g');
    vector<int> diff(sz + 1,0);
    auto pos = t.find(target);
    while(pos != string::npos) {
        int l = max(0,(int)pos + 7 + k - sz);
        int r = min(sz - 1,(int)pos);
        if(l <= r) {
            diff[l]++;
            diff[r + 1]--;
        }
        pos = t.find(target,pos + 1);
    }
    int ans = 0,cur = 0;
    for(int i = 0;i < sz;++i) {
        cur += diff[i];
        if(cur > 0) ans++;
    }
    cout << ans << "\n";
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int T = 1;
    cin >> T;
    while (T--) solve();
    return 0;
}
```

## 赛后补题

### B题
**题意**：
<p>给定一个正整数 p，你的任务是找到三个正整数 x<sub>1</sub>、x<sub>2</sub> 和 q，使得：</p>
<ul>
    <li>1 ≤ x<sub>1</sub> &lt; q，1 ≤ x<sub>2</sub> &lt; p；</li>
    <li>x<sub>1</sub><sup>2</sup> ≡ p (mod q)；</li>
    <li>x<sub>2</sub><sup>2</sup> ≡ q (mod p)。</li>
</ul>
<p>这里，a ≡ b (mod c) 表示 a 除以 c 的余数与 b 除以 c 的余数相同。如果存在多个解，输出任意一组合法的整数 (x<sub>1</sub>, x<sub>2</sub>, q) 即可。如果不存在这样的整数，则报告无法做到。</p>

---

**输入**：
第一行包含一个整数 T`（1 <= T <= 10^4）`，表示测试用例的数量。
接下来 T 行，每行包含一个整数 p`（2 <= p <= 10^9）`。
**输出**：
对于每个测试用例，输出一行：如果存在解，输出三个整数 x<sub>1</sub>、x<sub>2</sub> 和 q`（1 <= q <= 10^12，1 <= x1 < q，1 <= x2 < p）`，用空格分隔；如果不存在解，输出单词 Impossible。

---

**思路**：
构造性解法。令 x<sub>1</sub> = x<sub>2</sub> = x，q = x² − p，验证两个同余条件：
1. x<sub>1</sub><sup>2</sup> = x² = q + p ≡ p (mod q) ✓（因为 q + p 模 q 等于 p）
2. x<sub>2</sub><sup>2</sup> = x² = q + p，因此 x² mod p = (q + p) mod p = q mod p，即 x<sub>2</sub><sup>2</sup> ≡ q (mod p) ✓

接下来选择合适的 x 满足边界条件：
- x < p：取 x = ⌈√(2p)⌉，当 p > 2 时 √(2p) < p 成立。
- x < q：q = x² − p > x → x² − x − p > 0，当 x ≥ ⌈√(2p)⌉ 时显然成立。
- q ≤ 10¹²：x ≈ √(2p) ≤ √(2 × 10⁹) ≈ 44721，x² ≈ 2 × 10⁹ ≤ 10¹²，满足。

对于 p = 2 和 p = 3 的小情况直接特判输出。

**代码**：
```cpp
#include <bits/stdc++.h>
using namespace std;

using ll = long long;

void solve() {
    ll p;
    cin >> p;
    if (p == 2) {
        cout << "12 1 71\n";
        return;
    }
    if (p == 3) {
        cout << "4 1 13\n";
        return;
    }
    ll x = sqrt(2.0 * p);
    while (x * x < 2 * p) ++x;
    ll q = x * x - p;
    cout << x << ' ' << x << ' ' << q << '\n';
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int T;
    cin >> T;
    while (T--) solve();
    return 0;
}
```
