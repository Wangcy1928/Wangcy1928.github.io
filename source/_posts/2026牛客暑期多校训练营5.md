## 赛后补题

### E题 
**题意**：
<p>在数论领域，我们称一个函数 f(n) 是完全积性函数，当且仅当：</p>
<p style="text-align: center;">∀a·b = n, s.t. f(n) = f(a) · f(b)</p>
<p>这种积性这对 n 的每个非平凡的分解也都成立。也就是说，</p>
<p style="text-align: center;">∀n = w₁·w₂···w<sub>k</sub>, 1 &lt; w<sub>i</sub> &lt; n, s.t. f(n) = f(w₁)·f(w₂)···f(w<sub>k</sub>)</p>
<p>古明地恋不喜欢积性，于是她提出了一个完全非积性函数 g(n)，希望满足：</p>
<p style="text-align: center;">∀n = w₁·w₂···w<sub>k</sub>, 1 &lt; w<sub>i</sub> &lt; n, s.t. g(n) ≠ g(w₁)·g(w₂)···g(w<sub>k</sub>)</p>
<p>为了让问题更简单，古明地恋做了如下定义：</p>
<p style="text-align: center;">g(n) = 1, n = 1</p>
<p style="text-align: center;">g(n) = mex( { ∏g(w<sub>i</sub>) | n = ∏w<sub>i</sub>, 1 &lt; w<sub>i</sub> &lt; n } ∪ {0} ), n = 2, 3, 4, ···</p>
<p>其中 mex(S) 表示集合 S 中未出现过的最小的自然数。</p>
<p>古明地恋总是无意识少女，她希望你帮她计算 g 函数的值。具体而言，古明地恋会给你整数 N 以及参数 c（1 ≤ N ≤ 10⁷，1 ≤ c &lt; 998,244,353），你需要告诉她：</p>
<p style="text-align: center;">ans = ( ∑<sub>i=1</sub><sup>N</sup> g(i) × c<sup>i</sup> ) mod 998,244,353</p>

---

**输入**：
第一行包含两个整数 N, c`（1 ≤ N ≤ 10^7，1 ≤ c < 998244353）`。
**输出**：
输出一个整数，表示答案。

---

**思路**：
通过手动计算小值可以发现一个关键结论：**g(n) 的值仅由 n 的质因子个数（带重数）Ω(n) 决定**，且 g(n) 等于第 Ω(n) - 1 个质数（第 0 个"质数"定义为 1）。即：

- Ω(n) = 1（质数）→ g(n) = 1
- Ω(n) = 2 → g(n) = 2
- Ω(n) = 3 → g(n) = 3
- Ω(n) = 4 → g(n) = 5
- Ω(n) = k → g(n) = 第 k-1 个质数

**证明思路**：用数学归纳法。假设对于所有质因子个数小于 k 的数，结论成立。考虑 Ω(n) = k 的数 n，其所有非平凡分解对应的各因子质因子个数之和为 k，因此 g 值的乘积恰好是若干质数相乘，其所有可能的乘积值恰好覆盖 1 到 p_{k-1}-1 之间的所有整数，而 p_{k-1} 无法被表示，故 mex 结果为 p_{k-1}。

因此，解法为：
1. 用线性筛法预处理出 1 到 n 每个数的 Ω(i)（质因子总数，带重数）；
2. 同时筛出所有质数，按顺序存入 pri 数组，令 pri[0] = 1，pri[i] = 第 i 个质数；
3. 从 n 倒序枚举到 1，维护答案 ans：每次先将 g(i) = pri[Ω(i)-1] 加入 ans，再将 ans 乘以 c。倒序乘 c 的技巧等价于在累加时自动乘上 c^i。

时间复杂度 O(N)，空间复杂度 O(N)，可以通过 N = 10⁷ 的数据规模。

**代码**：
```cpp
#include <bits/stdc++.h>
using namespace std;

using ll = long long;
const ll MOD = 998244353;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n; ll c;
    cin >> n >> c;
    vector<int> primes;
    primes.reserve(n / 10);
    vector<int> omega(n + 1, 0); // 质因子总数（带重数）
    vector<bool> isComp(n + 1, false);
    omega[1] = 1; // 特殊处理，使得索引有效
    for (int i = 2; i <= n; ++i) {
        if (!isComp[i]) {
            primes.push_back(i);
            omega[i] = 1; // 质数，因子数为1
        }
        for (int p : primes) {
            if (1LL * i * p > n) break;
            isComp[i * p] = true;
            omega[i * p] = omega[i] + 1;
            if (i % p == 0) break;
        }
    }
    vector<ll> pri(primes.size() + 1);
    pri[0] = 1;
    for (int i = 0; i < (int)primes.size(); ++i) pri[i + 1] = primes[i];
    ll ans = 0;
    for (int i = n; i >= 1; --i) {
        int idx = omega[i] - 1;
        ans = (ans + pri[idx]) % MOD;
        ans = ans * c % MOD;
    }
    cout << ans << '\n';
    return 0;
}
```
