## 赛后补题

### F题
**题意**：
<p>在本题中，字母表被定义为小写英文字母从 a 到 z 的一个排列。在字母表 A 下，字母 x 的字典序小于字母 y 当且仅当在 A 中 x 出现在 y 之前。</p>
<p>在字母表 A 下，字符串 s 的字典序小于字符串 t 当且仅当满足以下两个条件之一：</p>
<ul>
<li>s 是 t 的真前缀。</li>
<li>存在一个整数 i (1 ≤ i ≤ min(|s|, |t|))，使得对于所有的 1 ≤ j &lt; i 都有 s<sub>j</sub> = t<sub>j</sub>，并且在字母表 A 下 s<sub>i</sub> 的字典序小于 t<sub>i</sub>。</li>
</ul>
<p>在字母表 A 下，字符串 s 被称为一个 Lyndon 串，当且仅当在 A 下它的字典序严格小于其所有的非空真后缀。</p>
<p>给定一个字符串 s。请计算有多少种不同的字母表 A 使得 s 在 A 下是一个 Lyndon 串。由于答案可能很大，请输出其对 2<sup>32</sup> 取模后的余数。</p>

---

**输入**：
每个测试点仅包含一行，给出一个字符串 s（2 ≤ |s| ≤ 2·10⁷）。
**输出**：
输出一个整数，表示使得 s 在字母表 A 下是 Lyndon 串的不同字母表 A 的数量对 2³² 取模的结果。

---

**思路**：
Lyndon 串的定义是：字符串严格小于它所有的非空真后缀。对于每个后缀 i（从第 i 个字符开始的后缀，2 ≤ i ≤ n），我们需要满足 s < s[i...n]。

对于每个后缀 i，计算它与原串的最长公共前缀 lcp（即 Z 函数值 z[i]）：
- 如果 z[i] = n - i + 1，说明该后缀是原串的前缀，即 s 是某个串的重复，此时无论什么字母表都不可能满足 s 严格小于该后缀，直接输出 0。
- 否则，第一个不同的位置：原串在位置 z[i]+1，后缀在位置 i+z[i]。记 v = s[z[i]+1]，u = s[i+z[i]]。要满足 s < s[i...n]，必须有 v 在字母表中的顺序小于 u，即 v 出现在 u 之前。

因此，问题转化为：统计 26 个字母的全排列中，满足所有形如 "v 必须在 u 之前" 的偏序约束的排列数。

使用状态压缩 DP 求解：
- dp[mask]：已经选了 mask 集合内的字母，满足所有约束条件的排列方案数。
- g[j]：bitmask，保存所有必须出现在字母 j 之前的字母集合。
- 初始状态：dp[0] = 1。
- 转移：枚举每个 mask，对于每个未选的字母 j，如果 mask 包含了 g[j] 的全部位（即 j 的所有前驱约束都已满足），则 dp[mask | (1<<j)] += dp[mask]。
- 答案为 dp[(1<<26)-1]。

使用 unsigned int 类型，利用无符号整数自然溢出自动完成对 2³² 取模。

时间复杂度：Z 函数 O(n)，状压 DP O(2²⁶ × 26)，可以通过。

**代码**：
```cpp
#include <bits/stdc++.h>

using namespace std;

vector<int> z_function_1based(const string& s) {
    int n = (int)s.size() - 1;
    vector<int> f(n + 1, 0);
    if (n == 0) return f;
    f[1] = n;
    int x = 2;
    if (2 <= n) {
        while (2 + f[2] <= n && s[1 + f[2]] == s[2 + f[2]]) f[2]++;
        x = 2;
    }
    for (int i = 3; i <= n; ++i) {
        if (f[i - x + 1] >= x + f[x] - i) {
            f[i] = max(0, x + f[x] - i);
            while (i + f[i] <= n && s[1 + f[i]] == s[i + f[i]]) f[i]++;
            x = i;
        } else {
            f[i] = f[i - x + 1];
        }
    }
    return f;
}

void solve() {
    string s;
    cin >> s;
    s = " " + s;
    int n = (int)s.size() - 1;
    auto f = z_function_1based(s);

    array<int, 26> g{};
    const int FULL = 1 << 26;
    vector<unsigned int> dp(FULL, 0);

    for (int i = 2; i <= n; ++i) {
        if (f[i] == n - i + 1) {
            cout << 0 << '\n';
            return;
        }
        int u = s[i + f[i]] - 'a';
        int v = s[f[i] + 1] - 'a';
        g[u] |= (1 << v);
    }

    dp[0] = 1;
    for (int mask = 0; mask < FULL - 1; ++mask) {
        if (dp[mask] == 0) continue;
        for (int j = 0; j < 26; ++j) {
            if ((mask & (1 << j)) == 0 && (mask & g[j]) == g[j]) {
                dp[mask | (1 << j)] += dp[mask];
            }
        }
    }
    cout << dp[FULL - 1] << '\n';
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    solve();
    return 0;
}
```
