## 比赛过程

### D题 天下第一武道会
**题意**：
<p>天下第一武道会汇聚了来自世界各地的 n 名武道家。这些选手的编号依次为 1, 2, ..., n。比赛开始前，两位大会工作人员分别提交了一份固定的优先级名单 P 和 Q。每份名单都恰好包含所有选手一次，但选手在两份名单中的排列顺序可能不同。</p>
<p>初始时，P = (p₁, p₂, ..., pₙ)，Q = (q₁, q₂, ..., qₙ)，其中两个序列都是 1, 2, ..., n 的排列。名单提交后，不能再改变其中选手的相对顺序。大会委员会按照以下规则模拟比赛：</p>
<p>只要仍有至少两名选手尚未淘汰，就可以进行一场比赛。令 u 和 v 分别为名单 P 和 Q 中第一个尚未淘汰的选手：</p>
<ul>
<li>如果 u = v，说明两位工作人员提名了同一名选手。由于一名选手不能与自己交手，并且工作人员不能跳过各自名单中的第一名选手，因此模拟将陷入僵局，无法再举行任何比赛。</li>
<li>否则，选手 u 和 v 将进行对战。在模拟中，选择一名选手 z ∈ {u, v} 作为败者。选手 z 将被淘汰，因此需要从 P 和 Q 中同时删除 z。两个名单中其余选手的相对顺序保持不变。</li>
</ul>
<p>在恰好进行了 n-1 场成功的比赛后，只会剩下一名选手。这名选手将成为天下第一武道会的冠军。你支持编号为 x 的选手。请判断是否存在一种比赛结果，使得模拟过程中从不陷入僵局，并最终让选手 x 成为冠军。如果存在，请输出任意一种合法的选手淘汰顺序。</p>

---

**输入**：
第一行包含两个整数 n 和 x（2 ≤ n ≤ 2×10⁵，1 ≤ x ≤ n），分别表示参赛选手的数量以及你希望成为冠军的选手编号。
第二行包含 n 个整数 p₁, p₂, ..., pₙ，保证 P 是 1, 2, ..., n 的一个排列。
第三行包含 n 个整数 q₁, q₂, ..., qₙ，保证 Q 是 1, 2, ..., n 的一个排列。
**输出**：
如果无法在模拟不陷入僵局的前提下让选手 x 成为冠军，在一行中输出 NO。
否则，首先在一行中输出 YES。第二行输出 n-1 个整数 z₁, z₂, ..., zₙ₋₁，表示在第 i 场比赛中被淘汰的选手。

---

**思路**：
双指针贪心策略。用两个指针 i 和 j 分别指向名单 P 和 Q 中第一个未淘汰的选手，用 used 数组标记已淘汰的选手。

核心策略：
1. 每次找到 P 和 Q 中第一个未淘汰的选手 u 和 v。
2. 如果 u == v：如果此时已经淘汰了 n-1 人（剩下的就是 x），则结束；否则陷入僵局，输出 NO。
3. 如果 u != x 且 v != x：比较 u 在 Q 中的位置和 v 在 P 中的位置。如果 u 在 Q 中出现得更早（posQ[u] < posP[v]），说明 u 更容易在后续造成冲突，优先淘汰 u；否则优先淘汰 v。
4. 如果其中一个是 x：淘汰另一个非 x 的选手。

这样做的目的是尽量推迟 x 的出现，同时避免两个指针指向同一个非 x 选手导致僵局。

时间复杂度 O(n)，可以通过 n = 2×10⁵ 的数据规模。

**代码**：
```cpp
#include <iostream>
#include <vector>
using namespace std;

void solve() {
    int n, x;
    cin >> n >> x;
    vector<int> p(n), q(n);
    vector<int> posP(n + 1), posQ(n + 1);
    for (int i = 0; i < n; ++i) {
        cin >> p[i];
        posP[p[i]] = i;
    }
    for (int i = 0; i < n; ++i) {
        cin >> q[i];
        posQ[q[i]] = i;
    }
    vector<int> ans;
    vector<bool> used(n + 1, false);
    int i = 0, j = 0;
    while (ans.size() < n - 1) {
        while (i < n && used[p[i]]) i++;
        while (j < n && used[q[j]]) j++;
        int u = p[i], v = q[j];
        if (u == v) {
            if (u == x && ans.size() == n - 1) break;
            cout << "NO\n";
            return;
        }
        if (u != x && v != x) {
            if (posQ[u] < posP[v]) {
                ans.push_back(u);
                used[u] = true;
                i++;
            } else {
                ans.push_back(v);
                used[v] = true;
                j++;
            }
        } else if (u != x) {
            used[u] = true;
            ans.push_back(u);
            i++;
        } else {
            used[v] = true;
            ans.push_back(v);
            j++;
        }
    }
    if (ans.size() != n - 1) {
        cout << "NO\n";
        return;
    }
    cout << "YES\n";
    for (int val : ans) {
        cout << val << " ";
    }
    cout << "\n";
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int t = 1;
    // cin >> t;
    while (t--) solve();
    return 0;
}
```

### K题 D-Mail 机构代号
**题意**：
<p>在使用 D-Mail 解读了 SERN 秘密数据库中的部分内容后，未来道具研究所发现了一份与时间旅行实验有关的研究机构名单。冈部伦太郎想在一封 D-Mail 中提及这些机构。由于 D-Mail 中能够使用的空间有限，桥田至（桶子）决定为每个机构分配一个简短且唯一的缩写。</p>
<p>最初，一个机构的缩写由其名称中每个单词的首字母依次连接而成，字母之间不添加空格。随后，桶子会反复细化每个仍与其他机构共用的缩写。</p>
<p>第一次细化某个缩写时，他会将对应机构名称中的第一个单词完整写出，而不再只使用它的首字母。第二次细化时，他还会将第二个单词完整写出，依此类推。</p>
<p>例如，Future Gadget Laboratory 的缩写会按照以下过程变化：FGL → FutureGL → FutureGadgetL → FutureGadgetLaboratory。</p>
<p>在每一轮中，当前仍与其他机构共用缩写的所有机构都会同时细化其缩写。只有在本轮所有需要细化的缩写都更新完毕后，桶子才会再次检查是否存在冲突。一个缩写一旦变得唯一，就会被永久锁定，此后不再发生变化。</p>
<p>如果本轮完整写出的单词只包含一个字母，那么缩写本身不会发生变化。尽管如此，该单词仍会被视为已经处理。如果之后还需要继续细化，桶子将处理下一个单词。</p>
<p>可以证明，经过有限轮操作后，所有缩写都会两两不同。请在冈部发送 D-Mail 之前，求出为每个机构分配的最终缩写。</p>

---

**输入**：
第一行包含一个整数 n（1 ≤ n ≤ 20），表示院校的数量。
接下来 n 行，每行包含一所院校的完整名称。每个名称由 1 至 20 个单词组成，相邻单词之间恰有一个空格。每个单词由 1 至 20 个英文字母组成。
**输出**：
输出 n 行，第 i 行包含第 i 个机构的最终缩写。

---

**思路**：
直接模拟整个过程。由于 n ≤ 20 且每个名称最多 20 个单词，数据规模很小，暴力模拟完全可行。

具体步骤：
1. 用 cnt[i] 记录第 i 个机构已经完整写出了前 cnt[i] 个单词。初始时 cnt[i] = 0。
2. suoxie(i) 函数根据 cnt[i] 生成当前缩写：前 cnt[i] 个单词完整写出，后面的单词只取首字母。
3. 每一轮：
   - 用 map 统计每个缩写对应的机构列表。
   - 找到第一个有冲突（对应机构数 > 1）的缩写。
   - 将所有有冲突的机构的 cnt 同时加 1。
   - 如果没有冲突了，结束循环。
4. 输出每个机构的最终缩写。

注意：所有冲突机构必须同时更新，不能边遍历边更新。

时间复杂度很低，完全在题目限制内。

**代码**：
```cpp
#include <iostream>
#include <string>
#include <vector>
#include <map>
#include <sstream>
using namespace std;

const int MAXN = 25;
int n;
vector<string> name[MAXN];
int cnt[MAXN];

string suoxie(int i) {
    string res;
    int sz = name[i].size();
    for (int j = 0; j < sz; ++j) {
        if (j < cnt[i]) res += name[i][j];
        else res += name[i][j][0];
    }
    return res;
}

void solve() {
    cin >> n;
    cin.ignore();
    for (int i = 0; i < n; ++i) {
        string line;
        getline(cin, line);
        name[i].clear();
        stringstream ss(line);
        string word;
        while (ss >> word) name[i].push_back(word);
        cnt[i] = 0;
    }
    while (1) {
        map<string, vector<int>> mp;
        for (int i = 0; i < n; ++i) {
            string s = suoxie(i);
            mp[s].push_back(i);
        }
        bool ok = false;
        for (auto &p : mp) {
            if (p.second.size() > 1) {
                ok = true;
                for (int idx : p.second) cnt[idx]++;
                break;
            }
        }
        if (!ok) break;
    }
    for (int i = 0; i < n; ++i) {
        cout << suoxie(i) << "\n";
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int t = 1;
    // cin >> t;
    while (t--) solve();
    return 0;
}
```

### L题 Bobo 的幸运取模
**题意**：
<p>Bobo 正在学习取模运算。对于两个正整数 a 和 b，他本应计算 a mod (b+1)。然而，他错误地先进行了取模运算，再加上 1，计算成了 (a mod b) + 1。</p>
<p>令人惊讶的是，对于某些 a 和 b，Bobo 的错误计算仍然能够得到正确结果。</p>
<p>给定一个正整数 n，请计算满足 1 ≤ a, b ≤ n 且</p>
<p style="text-align: center;">(a mod b) + 1 = a mod (b + 1)</p>
<p>的有序数对 (a, b) 的数量。</p>
<p>其中，x mod y 表示非负整数 x 除以正整数 y 所得到的余数。如果两个数对的第一个分量不同或第二个分量不同，则认为它们是不同的数对。</p>

---

**输入**：
输入仅包含一行，其中包含一个整数 n。保证 1 ≤ n ≤ 10¹²。
**输出**：
输出一个整数，表示满足要求的有序数对 (a, b) 的数量。

---

**思路**：

设带余除法 a = q·b + r，其中余数满足 0 ≤ r < b。

左边：a mod b = r，于是 (a mod b) + 1 = r + 1。
右边：a mod (b + 1)。

因为 0 ≤ r + 1 ≤ b < b + 1，r + 1 落在模 b + 1 的合法余数区间。
条件等式等价于同余式：
<p style="text-align: center;">a ≡ r + 1 (mod b + 1)</p>

把 a = qb + r 代入：
<p style="text-align: center;">qb + r ≡ r + 1 (mod b + 1)</p>
消去两边的 r：
<p style="text-align: center;">qb ≡ 1 (mod b + 1)</p>

注意模性质 b ≡ -1 (mod b + 1)，代入上式：
<p style="text-align: center;">-q ≡ 1 (mod b + 1) ⟹ q ≡ -1 (mod b + 1)</p>

于是 q 可以写成：
<p style="text-align: center;">q = t(b + 1) - 1，t ≥ 1</p>

再代回 a = qb + r：
<p style="text-align: center;">a = [t(b + 1) - 1] · b + r = t · b(b + 1) - b + r</p>
约束条件：0 ≤ r < b。

r 的取值范围 0 ≤ r < b，所以 -b + r 的范围是 -b ≤ -b + r ≤ -1。
得到：
<p style="text-align: center;">t · b(b + 1) - b ≤ a ≤ t · b(b + 1) - 1</p>

对固定的 b，t 取正整数，统计区间落在 [1, n] 内的 a 的个数。

令 L = b(b + 1)。
对于固定 b：
1. t 每增加 1，就对应一整段长度为 b 的合法 a。
   完整段的数量：k = ⌊n / L⌋，贡献 k · b。
2. 剩下余数部分 rₙ = n mod L。
   剩余部分合法区间是 [L - b, L - 1]，也就是 [b², L - 1]。
   如果 rₙ ≥ b²，则剩余部分贡献 rₙ - b² + 1；否则无贡献。

所以对每个 b，总贡献：
<p style="text-align: center;">add = k · b + max(0, rₙ - b² + 1)</p>
其中 L = b(b + 1)，k = ⌊n / L⌋，rₙ = n mod L。

b(b + 1) ≤ n，所以 b 只需要枚举到 √n，总复杂度 O(√n)，n ≤ 10¹² 时可以轻松通过。

**代码**：
```cpp
#include <iostream>
using namespace std;
typedef unsigned long long ull;

void solve() {
    ull n;
    cin >> n;
    ull ans = 0;
    for (int b = 1; 1ULL * b * b <= n; ++b) {
        ull len = 1ULL * b * (b + 1);
        ull k = n / len;
        ull r = n % len;
        ans += k * b;
        if (r >= 1ULL * b * b) {
            ans += r - 1ULL * b * b + 1;
        }
    }
    cout << ans << "\n";
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int t = 1;
    // cin >> t;
    while (t--) solve();
    return 0;
}
```
