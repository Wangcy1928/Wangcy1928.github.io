## 比赛过程

### B题
**题意**：
<p>汐与风子在一个浩瀚的数字宇宙中展开了一场智力对决：这个宇宙包含从 1 到 10¹⁰⁰ 的所有整数。对决开始时，汐从中精心选择恰好 n 个互不相同的数字；其余所有数字都归风子所有。</p>
<p>接下来的 n 轮中，两人逐一亮出自己选择的数字。每一轮都由风子先手，她从自己庞大的数字集合中亮出一个数字，汐必须立即用一个自己尚未打出的数字回应。这里有一条危险的规则：如果风子的数字严格小于汐回应的数字，风子就会立刻获胜。只有当汐的数字小于或等于风子的数字时，这一轮才能安全度过——两个数字都被丢弃，游戏继续。</p>
<p>要赢得对决，汐必须撑过全部 n 轮，且风子打出的数字绝不能小于汐回应的数字。</p>
<p>更糟的是，在游戏开始前，风子还施加了额外的限制。她交给汐一个包含 m 个指定数字的集合，并宣布汐的初始手牌必须包含其中每一个数字。</p>
<p>汐开始思考自己的胜算：在所有大小为 n 且包含这 m 个指定数字的手牌中，有多少副能够保证她拥有必胜策略，无论风子如何巧妙地选择出牌？答案对 998244353 取模。</p>

---

**输入**：
第一行包含测试用例数量 t（1 ≤ t ≤ 1000）。
每个测试用例第一行包含两个整数 n 和 m（1 ≤ m ≤ n ≤ 5000）。
第二行包含 m 个整数 a₁, a₂, ..., aₘ（1 ≤ aᵢ ≤ 10⁹），表示手牌中必须包含的指定数字，保证无重复。
所有测试用例的 n 之和不超过 5000。
**输出**：
对于每个测试用例，输出一个整数，表示能够保证汐拥有必胜策略的初始手牌数量对 998244353 取模后的结果。

---

**思路**：

**关键结论**：汐的手牌按升序排列为 s₁ < s₂ < ... < sₙ，她有必胜策略当且仅当 sₖ ≤ 2k - 1 对所有 k = 1..n 成立。

**推导**：
风子可以出的数字是所有不在汐手牌中的数字，按升序记为 t₁ < t₂ < ...。风子的最优策略是按 t₁, t₂, ..., tₙ 的顺序出牌，汐必须用 s₁, s₂, ..., sₙ 贪心回应（用 ≤ 对方数字的最小手牌）。汐要必胜，必须满足 sₖ ≤ tₖ 对所有 k。

tₖ 是第 k 个不在手牌中的数字。sₖ ≤ tₖ 等价于：在前 sₖ 个数字中，不在手牌中的数字少于 k 个。前 sₖ 个数字中有 k 个在手牌中，有 sₖ - k 个不在手牌中，因此 sₖ - k < k，即 sₖ ≤ 2k - 1。

由此可知，所有手牌数字都必须 ≤ 2n - 1（因为 sₙ ≤ 2n - 1）。若指定数字中有 > 2n - 1 的，或有重复，答案为 0。

**DP 计数**：
令 N = 2n - 1，从小到大遍历数字 1 到 N。
- dp[j]：已选 j 个数字的方案数。
- 若数字 i 是必选的，只能选；否则可选或不选。
- 在奇数位置 i = 2k - 1 处，必须已选至少 k 个数字（否则第 k 小的数字会 > 2k - 1），因此将 dp[0..k-1] 清零。

最终答案为 dp[n]。

时间复杂度 O(n²)，所有测试用例 n 之和 ≤ 5000，可以通过。

**代码**：
```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

using ll = long long;
const int MOD = 998244353;

void solve() {
    int n, m;
    cin >> n >> m;
    vector<ll> a(m);
    for (int i = 0; i < m; ++i) cin >> a[i];
    int N = 2 * n - 1;
    vector<bool> must(N + 1, false);
    bool ok = true;
    for (const int& x : a) {
        if (x > N) { ok = false; break; }
        if (must[x]) { ok = false; break; }
        must[x] = true;
    }
    if (!ok) { cout << "0\n"; return; }
    vector<ll> dp(n + 1, 0), nxt_dp(n + 1, 0);
    dp[0] = 1;
    for (int i = 1; i <= N; ++i) {
        fill(nxt_dp.begin(), nxt_dp.end(), 0);
        for (int j = 0; j <= n; ++j) {
            if (dp[j] == 0) continue;
            if (must[i]) {
                if (j < n) nxt_dp[j + 1] = (nxt_dp[j + 1] + dp[j]) % MOD;
            } else {
                nxt_dp[j] = (nxt_dp[j] + dp[j]) % MOD;
                if (j < n) nxt_dp[j + 1] = (nxt_dp[j + 1] + dp[j]) % MOD;
            }
        }
        if (i % 2 == 1) {
            int need = (i + 1) / 2;
            for (int j = 0; j < need; ++j) nxt_dp[j] = 0;
        }
        dp.swap(nxt_dp);
    }
    cout << dp[n] % MOD << "\n";
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int t = 1;
    cin >> t;
    while (t--) solve();
    return 0;
}
```

### I题
**题意**：
<p>大豆参加了一场有 2n 名参赛者的比赛，目前比赛已经进入决赛轮。参赛者的编号从 1 到 2n。在决赛轮中，对于每个 i = 1, 2, ..., n，参赛者 2i-1 与参赛者 2i 进行比赛。在每场比赛中，m 分可以以任意方式分配给两名参赛者，但每人获得的分数必须是一个非负实数。</p>
<p>决赛轮开始前，参赛者 i 的初始分数为 aᵢ。一名参赛者的最终分数等于其初始分数加上其在本轮中获得的分数。</p>
<p>大豆是参赛者 1。他想知道自己最好和最差的最终排名。具体而言，考虑每组中 m 分的所有合法分配方式，他想知道：</p>
<ul>
<li>最少可能有多少名参赛者的最终分数严格大于他的最终分数，</li>
<li>最多可能有多少名参赛者的最终分数严格大于他的最终分数。</li>
</ul>

---

**输入**：
第一行包含测试用例数量 t（1 ≤ t ≤ 10⁴）。
每个测试用例第一行包含两个整数 n 和 m（1 ≤ n ≤ 2×10⁵，1 ≤ m ≤ 10⁹）。
第二行包含 2n 个整数 a₁, a₂, ..., a₂ₙ（1 ≤ aᵢ ≤ 10⁹）。
所有测试用例的 n 之和不超过 2×10⁵。
**输出**：
对于每个测试用例，输出两个整数——最少和最多可能有多少名参赛者的最终分数严格大于大豆的最终分数。

---

**思路**：

大豆是参赛者 1，与参赛者 2 配对。其他配对为 (2i-1, 2i)，i = 2..n。

**最少人数（大豆拿全部 m 分）**：
大豆最终分数 s = a₁ + m，参赛者 2 得 0 分，最终分数为 a₂。
对于其他配对 (u, v)，两人分数和增加 m：
- 若 u ≤ s 且 v ≤ s 且 u + v + m ≤ 2s：可以分配使两人都不超过 s，贡献 0。
- 否则若 u ≤ s 或 v ≤ s：最多只能让一人不超过 s，另一人必超过 s，贡献 1。
- 否则两人初始都 > s，无论怎么分配都超过 s，贡献 2。

**最多人数（大豆拿 0 分）**：
大豆最终分数 s = a₁，参赛者 2 得全部 m 分，最终分数为 a₂ + m。
对于其他配对 (u, v)：
- 若 u + m > s 且 v + m > s 且 u + v + m > 2s：可以分配使两人都超过 s，贡献 2。
- 否则若 max(u, v) + m > s：至少有一人可以超过 s，贡献 1。
- 否则无人能超过 s，贡献 0。

时间复杂度 O(n)，可以通过。

**代码**：
```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

using ll = long long;
int n;
ll m;

int cnt_min(const vector<ll>& a, ll s) {
    int cnt = 0;
    ll opp = a[1] + m - (s - a[0]);
    if (opp > s) cnt++;
    for (int i = 2; i < 2 * n; i += 2) {
        ll u = a[i], v = a[i + 1];
        ll T = u + v + m;
        if (u <= s && v <= s && T <= 2 * s) continue;
        else if (u <= s || v <= s) cnt++;
        else cnt += 2;
    }
    return cnt;
}

int cnt_max(const vector<ll>& a, ll s) {
    int cnt = 0;
    ll opp = a[1] + m - (s - a[0]);
    if (opp > s) cnt++;
    for (int i = 2; i < 2 * n; i += 2) {
        ll u = a[i], v = a[i + 1];
        if (u + m > s && v + m > s && u + v + m > 2 * s) cnt += 2;
        else if (max(u, v) + m > s) cnt++;
    }
    return cnt;
}

void solve() {
    cin >> n >> m;
    vector<ll> a(2 * n);
    for (int i = 0; i < 2 * n; ++i) cin >> a[i];
    int Min = cnt_min(a, a[0] + m);
    int Max = cnt_max(a, a[0]);
    cout << Min << " " << Max << "\n";
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int t = 1;
    cin >> t;
    while (t--) solve();
    return 0;
}
```
