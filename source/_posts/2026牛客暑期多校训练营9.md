## 赛后补题

### D题
**题意**：
<p>给定一棵有 n 个结点的树，结点编号为 1 到 n，树根为 1，每条边长度为 1。</p>
<p>有 m 个人。第 i 个人会在第 sᵢ 秒出现在结点 xᵢ，并立刻以每秒 1 单位长度的速度沿最短路向结点 1 移动。</p>
<p>如果某一时刻，有至少两个人处在同一个位置，则这些人会同时消失。位置可以是结点，也可以是边的内部。</p>
<p>如果某个人到达结点 1 时没有与其他人相遇，则他成功逃脱，并立刻从树上移出。</p>
<p>请问哪些人会成功逃脱。</p>

---

**输入**：
第一行包含两个整数 n, m（1 ≤ n, m ≤ 2×10⁵）。
接下来 n-1 行，每行包含两个整数 u, v（1 ≤ u, v ≤ n，u ≠ v），表示树上有一条连接 u 和 v 的边。
接下来 m 行，每行包含两个整数 xᵢ, sᵢ（1 ≤ xᵢ ≤ n，0 ≤ sᵢ ≤ 10⁹），表示第 i 个人出现的结点和出现时间。
**输出**：
输出一个长度为 m 的 01 串。第 i 个字符为 1 表示第 i 个人成功逃脱，为 0 表示消失。

---

**思路**：

**关键观察**：第 i 个人到达根结点 1 的时间为 Tᵢ = sᵢ + depth[xᵢ]。如果两个人的 T 值相同，他们一定会在到达根之前相遇并同时消失。

**证明**：设两人到达根的时间均为 T。在时刻 t（两人都已出发后），从 x 出发的人位于距离根 T - t 的位置，从 y 出发的人也位于距离根 T - t 的位置。当两人都进入从 LCA(x, y) 到根的公共路径后（此时 t = T - depth[LCA]），他们处在同一位置，因此相遇消失。

**算法**：树上启发式合并（DSU on Tree）。
1. BFS 求出每个结点的 parent 和 depth，并得到 BFS 序。
2. 按 BFS 序逆序（从叶子到根）处理每个结点 u：
   - 维护一个哈希表 mp[T] = 人员列表，表示当前子树中到达根时间为 T 且尚未消失的人。
   - 合并所有子结点的哈希表（小的合并到大的，保证复杂度）。
   - 将当前结点上的人加入哈希表。
   - 若某个 T 对应的人数 ≥ 2，这些人全部标记为 eliminated，并从哈希表中移除（他们已相遇消失，不会继续向上移动）。
3. 最终输出 01 串。

时间复杂度 O(n log n)，可以通过 n, m ≤ 2×10⁵ 的数据规模。

**代码**：
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<vector<int>> adj(n + 1);
    for (int i = 0; i < n - 1; i++) {
        int u, v;
        cin >> u >> v;
        adj[u].push_back(v);
        adj[v].push_back(u);
    }
    vector<int> parent(n + 1, 0), depth(n + 1, 0), order;
    queue<int> q;
    q.push(1);
    vector<bool> vis(n + 1, false);
    vis[1] = true;
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        order.push_back(u);
        for (int v : adj[u]) {
            if (!vis[v]) {
                vis[v] = true;
                parent[v] = u;
                depth[v] = depth[u] + 1;
                q.push(v);
            }
        }
    }
    vector<vector<int>> people_at_node(n + 1);
    vector<long long> T_val(m + 1);
    vector<bool> eliminated(m + 1, false);
    for (int i = 1; i <= m; i++) {
        int x, s;
        cin >> x >> s;
        T_val[i] = (long long)s + depth[x];
        people_at_node[x].push_back(i);
    }
    vector<unordered_map<long long, vector<int>>*> mp(n + 1, nullptr);
    for (int idx = (int)order.size() - 1; idx >= 0; --idx) {
        int u = order[idx];
        if (mp[u] == nullptr) {
            mp[u] = new unordered_map<long long, vector<int>>();
        }
        vector<long long> cand;
        for (int v : adj[u]) {
            if (v == parent[u]) continue;
            if (mp[v] == nullptr) continue;
            if (mp[u]->size() < mp[v]->size()) {
                swap(mp[u], mp[v]);
            }
            for (auto &entry : *mp[v]) {
                long long T = entry.first;
                vector<int> &vec_small = entry.second;
                auto it = mp[u]->find(T);
                if (it == mp[u]->end()) {
                    (*mp[u])[T] = move(vec_small);
                } else {
                    vector<int> &vec_big = it->second;
                    int old_size = (int)vec_big.size();
                    vec_big.insert(vec_big.end(),
                                   make_move_iterator(vec_small.begin()),
                                   make_move_iterator(vec_small.end()));
                    vec_small.clear();
                    if (old_size < 2 && (int)vec_big.size() >= 2) {
                        cand.push_back(T);
                    }
                }
            }
            delete mp[v];
            mp[v] = nullptr;
        }
        for (int person : people_at_node[u]) {
            long long T = T_val[person];
            vector<int> &vec = (*mp[u])[T];
            int old_size = (int)vec.size();
            vec.push_back(person);
            if (old_size < 2 && (int)vec.size() >= 2) {
                cand.push_back(T);
            }
        }
        for (long long T : cand) {
            auto it = mp[u]->find(T);
            if (it != mp[u]->end() && it->second.size() >= 2) {
                for (int p : it->second) {
                    eliminated[p] = true;
                }
                mp[u]->erase(it);
            }
        }
    }
    string ans;
    ans.reserve(m);
    for (int i = 1; i <= m; i++) {
        ans += (eliminated[i] ? '0' : '1');
    }
    cout << ans << "\n";
    for (int i = 1; i <= n; i++) {
        if (mp[i]) delete mp[i];
    }
    return 0;
}
```
